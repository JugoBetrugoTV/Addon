# Battlefield: Python Edition

2D Top-Down Conquest-Mode Shooter inspiriert von Battlefield.

## Features

- **Conquest-Modus**: 5 Flaggen erobern und halten
- **4 Klassen**: Sturm, Ingenieur, Unterstuetzung, Aufklaerer
- **Fahrzeuge**: Panzer und Jeeps
- **32 Spieler**: 16 vs 16 (KI-gesteuert)
- **Ticket-System**: Team verliert Tickets bei Toeden und Flaggen-Nachteil
- **Minimap, Kill-Feed, Partikel-Effekte**

## Steuerung

| Taste | Aktion |
|-------|--------|
| WASD | Bewegen |
| Maus | Zielen |
| LMB | Schiessen |
| RMB | Rakete (Ingenieur) |
| R | Nachladen |
| F | Fahrzeug ein-/aussteigen |
| ESC | Menu |

## Build

```
build.bat
```

EXE wird erstellt in `dist/Battlefield Python Edition.exe`

## Voraussetzungen

- Python 3.8+
- pygame
