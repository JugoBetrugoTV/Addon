EpicDamageMeter Textures
========================

This folder contains custom textures for the addon.

Required Textures:
- icon.tga (or .blp) - Main addon icon (64x64)
- statusbar_smooth.tga - Smooth gradient statusbar
- statusbar_gradient.tga - Gradient statusbar
- statusbar_glossy.tga - Glossy statusbar
- statusbar_modern.tga - Modern flat statusbar
- statusbar_flat.tga - Flat solid statusbar
- border_modern.tga - Modern border texture
- border_simple.tga - Simple border texture

Texture Specifications:
- Status bars: 256x32 pixels, horizontal gradient
- Borders: 64x64 pixels, 9-slice compatible
- Icon: 64x64 pixels

For best results, textures should be in TGA or BLP format.
Power of 2 dimensions recommended (32, 64, 128, 256, etc.)

The addon will fall back to Blizzard default textures if these
files are not present.
